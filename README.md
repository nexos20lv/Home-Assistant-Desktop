## 💜 Fonctionnalités
- Intégration parfaite avec votre serveur Home Assistant local ou distant.
- Design épuré pour un accès rapide à vos entités.
- Support du multi-plateforme grâce à Electron.

## 🛠️ Installation
1. Clonez le dépôt : `git clone https://github.com/nexos20lv/Home-Assistant-Desktop.git`
2. Installez les dépendances : `npm install`
3. Lancez l'application : `npm start`
4. Compilez l'app : `npm run build`
